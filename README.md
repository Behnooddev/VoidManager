# VoidManager

VoidManager is a private, local-first application for organizing personal information: people, contact details, accounts, financial data, relationships, notes, photos and attachments, plus a personal vault for the user's own data. It stores everything on the device, works offline and does not require an account or a server.

Android is the first target platform. Desktop (Windows first, then Linux and macOS) shares the same core through Kotlin Multiplatform. iOS is not planned but the architecture does not rule it out.

## Status

The project is in Phase 0 (architecture and technology selection). There is no application code yet. The documents under `docs/` describe the intended design; none of it is implemented, and none of it should be read as a description of shipped behavior.

See `docs/roadmap.md` for the phase plan and `docs/open-decisions.md` for the items that still need a decision.
